\section{Programm: Das Spielfeld}
\label{sec:c:spielfeld}

Nachdem Ihr so viel Neues gelernt und kennengelernt habt, ist es nun Zeit, ein wenig zu Spielen. In diesem Kapitel soll das ``Lauflicht'', das Ihr in Kapitel~\ref{sec:c:lauflicht} und~\ref{sec:c:lauflicht-vertikal} gebaut habt, in beide Richtungen funktionieren -- also sowohl waagerecht als auch senkrecht. Wir fangen damit an, ein Zeichen an einer zufälligen Stelle auf dem Bildschirm auszugeben -- also nicht mehr nur auf einer festen Linie, sondern irgendwo im Feld. Damit legt Ihr die Grundlage für die Regensimulation, die wir später bauen.

Das Grundgerüst Eures Progamms mit den bekannten Hilfsfunktionen ist (\source{https://raw.githubusercontent.com/jsawinski/twin-c-course/refs/heads/main/src/c/08_spielfeld_1.c}):\footnote{%
    Wenn Ihr auf ``Quellcode'' klickt, bekommt Ihr den Code zum Kopieren in einem Browserfenster.
}
\cppinput[numbers=none]{c/08_spielfeld_1.c}

\noindent
Hier sind zwei neue Hilfsfunktion hinzugekommen. Das \codeinline{konsole_loeschen()} verwendet eine neue ANSI-Escape-Sequenz (vergleiche Kapitel~\ref{sec:c:lauflicht-vertikal}), die den Inhalt der Konsole löscht -- wie auch der Kommentar im Code sagt. Die zweite Hilfsfunktion gibt ein beliebiges Zeichen auf dem Bildschirm aus. Da das \codeinline{fflush(stdout)} hier schon eingebaut ist, braucht Ihr dieses Kommando nicht mehr zu verwendent. Wenn Ihr nun, zum Beispiel, einen Stern auf dem Bildschirm ausgeben wollt, dann schreibt Ihr:
\begin{code}[numbers=none]
    konsole_zeichen('*');
\end{code}
