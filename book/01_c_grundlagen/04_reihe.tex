\section{Programm: Reihen}
\label{sec:c:reihen}

Die Zahl $\pi$ ist eine sehr wichtige Zahl in der Mathematik. Sie lässt sich aus einer unendlichen Reihe berechnen:
\begin{equation*}
  \frac{\pi}{4} = 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \frac{1}{11} + \ldots
\end{equation*}
Die Reihe geht also unendlich weiter. In der Praxis kann man aber nur endlich viele Terme berechnen. Je mehr Terme man berechnet, desto genauer wird das Ergebnis. Im folgenden Programm wird diese Summe mit $1000000$ Schritten berechnet (auf der Konsole wird $\pi$ ausgegeben, indem man obige Summe einfach vervierfacht):

\begin{exercise}
  Einige von Euch haben sich vielleicht schon ein paar Stellen von $\pi$ gemerkt und werden feststellen, dass das Ergebnis sechs Stellen nach dem Komma abweicht. Ihr könnt einmal das \texttt{printf()} mit folgernder Anweisung
  tauschen, die Euch die Abweichung von $\pi$ anzeigt:
\begin{code}
printf("%9d Pi: %.15f  (% .15f)\n", i, 4*pi, 4*pi - 3.14159265358979323846);
\end{code}
  Wie groß wäre die Abweichung nach 1000 Schritten?
  \begin{solution}
    Ab der 7. Programmzeile wird
\begin{code}
double n = 2*i + 1  
n = 1.0/n;
\end{code}
  berechnet. Dieses $n$ wird dann zu dem Ergebnis hinzugezäht oder abgezogen – damit ist die Abweichung für $i = 1000$:
\begin{equation*}
  \Delta\pi = 4\frac{1}{2 n + 1} = \frac{4}{2001} \approx 0,002\,.
\end{equation*}
  \end{solution}
\end{exercise}

\paragraph{Erklärung:}

\begin{description}
  \item[\texttt{double pi = 1.0;}] \hfill\\
    Wir initialisieren die erste Fibonacci-Zahl mit 0. Es handelt sich dabei um eine Gleitkommazahl, also eine Zahl mit Kommastellen.
  \item[\texttt{for (int i = 1; i <= 1000000; i++)}] \hfill\\
    Das ist eine Schleifenanweisung, die wir schon im vorhergehenden Kapitel kennengelernt haben. Neu ist hier allerdings, wie $i$ gezählt wird. Der Operator \texttt{++} sagt, dass $i$ um eins erhöht werden soll. Wie er genau funktioniert, werden wir aber später noch kennen lernen.
  \item[\texttt{double n = 2*i + 1}] \hfill\\
    Oben wurde beschrieben, wie man $\pi$ aus einer Summe berechnen kann. Wenn nochmal schaut, dann sind in der Reihe immer die ungeraden Zahlen $3$, $5$, $7$, usw. Unser Zähler $i$ liefert jedoch die Zahlen $1$, $2$, $3$, ... Die Rechnung $2\cdot i + 1$ liefert nun genau diese ungeraden Zahlen, da wir $\pi$ aber mit einer Gleitkommazahl berechnen muss auch das eine Gleitkommazahl sein.
  \item[\texttt{n = 1.0 / n}] \hfill\\
    Was wir addieren oder subtrahieren müssen, ist aber nicht $3$, $5$, $7$, usw. sondern $1/3$, $1/5$, $1/7$, usw.,
    wir bilden also hier den Kehrwert $n\leftarrow \frac{1}{n}$ (in Worten: $n$ wird der Kehrwert $\frac{1}{n}$ zugeordnet).
  \item[if (i \& 1)] \hfill\\
    Da wir abwechselnd addieren und subtrahieren müssen, muss eine Entscheidung getroffen werden, was von beidem stattfindet. Das macht man mit dem \texttt{if}:
\begin{verbatim}
if (Bedingung) {
    // Befehle, die ausgeführt werden, 
    // wenn die Bedingung "wahr" (true) ist.
}
else {
    // Befehle, die ausgeführt werden, 
    // wenn die Bedingung "falsch" (false) ist.
}
\end{verbatim}
    Bemerkt, dass wir die geschweiften Klammern im Code weglassen konnten, weil es nur ein einziger Befehl ist
    (das gleiche gilt übrigens auch für die \texttt{for}-Schleife).

    Die Bedingung ist nun \texttt{i \& 1}. Wenn ihr Euch an das Kapitel über ``Bitweise Operationen'' erinnert, dann prüft diese Bedingung ob das 0-te Bit eine 1 ist. Das ist genau dann der Fall, wenn $i$ ungerade ist.
    Bildlich sieht das so aus:
\begin{verbatim}
      i              i & 1
    0    00000000    00000000
    1    00000001    00000001
    2    00000010    00000000
    3    00000011    00000001
    4    00000100    00000000
    ...
\end{verbatim}

\end{description}

\paragraph{Merke:}

\begin{itemize}[noitemsep]
    \item Für Gleitkommazahlen verwenden wir den Datentyp \codeinline{double}.
    \item Mit bitweisen Operationen kann man z.B.\ feststellen, ob eine Zahl gerade oder ungerade ist.
\end{itemize}
