\section{Reihen}
\label{sec:c:reihen}

Die Zahl $\pi$ ist eine sehr wichtige Zahl in der Mathematik. Sie lässt sich aus einer unendlichen Reihe berechnen:
\begin{equation*}
  \frac{\pi}{4} = 1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \frac{1}{11} + \ldots
\end{equation*}
Die Reihe geht also unendlich weiter. In der Praxis kann man aber nur endlich viele Terme berechnen. Je mehr Terme man berechnet, desto genauer wird das Ergebnis. In der folgenden C-Datei wird die Reihe bis zum Term $1/1999999$ berechnet (das sind etwa sechs Stellen nach dem Komma). Das Ergebnis wird dann mit 4 multipliziert, um $\pi$ zu erhalten.

\begin{code}
#include <stdio.h>

int main() {
    double pi = 1.0;
    for (int i = 1; i < 1000000; i++) {
        double n = 2*i + 1;     // 3, 5, 7, 9, ...

        if (i & 1)
            pi -= 1.0/n;
        else
            pi += 1.0/n;
    }   

    printf("Pi: %f\n", 4*pi);
    return 0;
}
\end{code}
