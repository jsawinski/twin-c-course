\section{Lauf"|licht}
\label{sec:c:lauflicht}

Im folgenden C-Programm wird ein sogenanntes ``Lauf"|licht'' erzeugt. Dabei wird ein Sternchen von links nach rechts über den Bildschirm bewegt. Das Programm läuft dabei unendlich lange, bis es mit \texttt{Strg+C} abgebrochen wird.

\begin{code}
#define __GNU_SOURCE
#include <stdio.h>
#include <unistd.h>

int main() {
    while(1) {
        for (int i = 0; i < 20; i++) {
            printf("\r");
            for (int j = 0; j < 20; j++) {
                if (i == j)
                    printf("*");
                else
                    printf(" ");
            }
            usleep(100000);
        }
    }

    return 0;
}
\end{code}
